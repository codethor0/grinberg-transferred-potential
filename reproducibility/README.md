# Reproducibility supplement

## Scope

This supplement reproduces the manuscript's **fully synthetic null benchmark**, nine original figures, and final PDF. It does not download, reconstruct, or analyze human EEG, and it does not recreate Grinberg's historical recordings. Reproduction of the benchmark establishes computational repeatability for the demonstrated stationary synthetic null; it does not establish calibration for real EEG or validate a physical communication mechanism.

## One-command reproduction

From any current directory, run:

```sh
sh reproducibility/run_all.sh
```

The script resolves all paths relative to its own location. It performs five steps:

1. Runs `synthetic_null_demo.py` with seed `20261025` and writes `simulation_check.txt` and `results.json`.
2. Regenerates the nine base figures with `make_figures.py`.
3. Regenerates the four refined schematics with `refine_figures.py`.
4. Assembles nine PNG/PDF figure pairs plus `figure7_results.json` in `figures/`.
5. Builds `manuscript/Grinberg_Transferred_Potential_Research_Paper.pdf` from `manuscript/Manuscript_Source.md` using Pandoc, XeLaTeX, and `manuscript.template`.

The script uses `python` by default. A compatible interpreter can be selected explicitly:

```sh
PYTHON=python3 sh reproducibility/run_all.sh
```

Run `run_all.sh` on a copy of the extracted candidate. It overwrites `results.json`, `simulation_check.txt`, the figures, and the PDF in place, so regenerated files will not match `SHA256SUMS.txt` byte for byte after regeneration. Compare regenerated outputs by content: rejection counts must match exactly, while floating-point diagnostics such as median $p$ values can differ in their last digits across NumPy and SciPy versions.

## Expected benchmark output

The two bands are generated sequentially from the same pseudo-random generator. With the pinned environment in `requirements_executed.txt`, the rejection proportions are:

| Band | Naive Pearson p < 0.05 | Circular-shift p ≤ 0.05 | Naive rejections | Shift rejections |
|---|---:|---:|---:|---:|
| 13–35 Hz | 0.4328 | 0.0454 | 2,164 / 5,000 | 227 / 5,000 |
| 4–12 Hz | 0.6206 | 0.0508 | 3,103 / 5,000 | 254 / 5,000 |

The console also reports median p values of `0.0908` and `0.4961` for the first band, and `0.0087` and `0.4922` for the second band. These are simulation diagnostics, not historical effect estimates. Changing random-library versions, band order, tie handling, or the seed can change finite-sample results.

For a benchmark-only check:

```sh
python reproducibility/synthetic_null_demo.py
```

Compare the generated `results.json` with the values above and Table 3 of the manuscript. The benchmark uses 5,000 independent pairs per band, 128 samples per recording, a sampling rate of 256 Hz, and all 128 circular shifts. No network access or external dataset is required.

## Dependencies

Install the exact Python packages listed in `requirements_executed.txt`. The PDF build additionally requires Pandoc 3.12.1, a XeLaTeX installation, the `xurl` LaTeX package, and Palatino/Helvetica-compatible fonts. The observed build environment is documented in `ENVIRONMENT.md`. Paths are portable; pixel-identical rendering across operating systems and font implementations is not claimed.

## Figures

All nine figures are original schematic or synthetic-result graphics generated by the included Python code. Figures 2, 3, 5, and 9 are refined replacements for their corresponding base figures. They are not photographs, histological images, or reconstructions of undocumented historical wiring. PNG files are used in the manuscript builds; matching vector PDFs are supplied for inspection and reuse subject to the author's eventual license decision.

## Word manuscript

`manuscript/Grinberg_Transferred_Potential_Research_Paper.docx` is a synchronized editable artifact containing native Word equations and the same nine embedded PNG figures. It is **not regenerated** by `run_all.sh`, which keeps the numerical and PDF workflow independent of the Word toolchain. To rebuild it from the canonical Markdown, run from the extracted candidate root:

```sh
python3 reproducibility/build_docx.py . reproducibility/reference_styles.docx
```

The DOCX build requires Pandoc 3.12.1 and the pinned `lxml` package. The supplied style reference is a style-only derivative of this manuscript's own editable output, not third-party content. The build writes the DOCX in place, so checksums must be regenerated afterward. The final DOCX is checked separately for OOXML validity, text synchronization, revision/comment absence, image hashes, explicit table widths, repeating headers, unsplit rows, and rendered layout.
